## Overview

A 15-second click game written with Python's turtle module: the turtle jumps to a random spot every second and you score by clicking it before time runs out.

**Quick start:** `python main.py`

## Proje hakkında

Python `turtle` modülüyle yazılmış 15 saniyelik bir tıklama oyunu. Kaplumbağa her saniye rastgele bir konuma zıplar; süre bitmeden üzerine tıklayarak puan toplanır.

## Özellikler

- Rastgele konuma zıplayan kaplumbağa
- Anlık skor ve geri sayım
- Süre bitince “game over!” ekranı

## Kurulum ve çalıştırma

Ek bağımlılık yoktur.

```bash
python main.py
```
